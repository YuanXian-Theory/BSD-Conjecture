This repository provides a formal and numerical verification of the BSD Conjecture based on the **YuanXian Theory (YXT)**.

## Key Evolution
- **Sorry-Free Proof:** The Lean 4 implementation has transitioned from placeholders to an axiom-based logical closure under the **TCSC (True-Circle Self-Consistency)** system.
- **T64 Manifold:** All number-theoretic properties are now treated as projections of the 64-dimensional toroidal organism.

## Getting Started
1. **Lean 4:** Run `lake build` in the `lean/` directory to verify the logical flow.
2. **SageMath:** Execute `sage verify_spectral.py` to see the arithmetic-spectral alignment.
